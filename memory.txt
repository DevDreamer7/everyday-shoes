Everyday Shoes - Inventory Management App

Stack: Next.js 16.2.6 + Tailwind CSS v4 + Supabase
Location: C:\Users\aagam\Documents\everyday-shoes
User: Aagam, single store, wants minimalist beautiful UI

Features:
- Dashboard with stats & out of stock alerts
- Inventory (full CRUD: products, sizes, colors, brands, SKUs, pricing)
- POS (sales, cart, grouped product display, customer selection, cash/card)
- Customers (database with purchase tracking)
- Suppliers (contact management)
- Out of Stock page (only shows products with stock = 0)
- Reports (revenue charts, top products, 7/30/90 day filters)

Setup:
1. Create Supabase project
2. Update .env.local with URL & anon key
3. Run src/lib/schema.sql in Supabase SQL Editor
4. npm run dev

-- CURRENT SCHEMA NOTES --
Sale Items table uses cascade delete:
product_id uuid references products(id) on delete cascade
When a product is deleted, all related sale_items are automatically deleted.
